# Handoff

Pick up where you left off.

Handoff is a Chrome extension that helps users transfer project context between AI assistants.

## Problem

When users hit usage limits on one AI platform, they often spend multiple prompts rebuilding context on another platform.

## Solution

Generate a structured transfer prompt containing:

- Project Name
- Current Goal
- Completed Work
- Current Issue
- Next Step
